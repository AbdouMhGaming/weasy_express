All fixes are live and working. Here's what was done to make the admin dashboard significantly lighter and faster:

1. Lazy-loaded all sub-views — Previously all 7 views (Performance, Charges, Commissions, Settings, Workers, Décharges, OfficeDashboard) were bundled and parsed upfront. Now they load on-demand with React.lazy + Suspense, so opening /admin only loads the code for the view you're actually on.

2. Memoized the Sidebar — The sidebar was re-rendering on every state change in the parent (e.g. every time partners or offices data updated). Wrapping it with memo means it only re-renders when its own props actually change.

3. Memoized KPI cards — The 6 KPI cards with inline SVG icons were rebuilt on every render cycle. Now they're cached with useMemo and only recalculate when stats change.

4. Debounced the order search — Typing in the search box now waits 300ms before filtering, instead of re-filtering the entire orders list on every keystroke.

5. Removed a redundant double-fetch — Saving or deleting an order was triggering a full refetch of all partners and all offices (totally unrelated data) on top of the stats refresh. That extra load is gone.
